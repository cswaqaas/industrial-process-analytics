# Excel Export

Excel files are generated by the backend using `openpyxl`.

Exporter:

```text
backend/app/exports/excel_report.py
```

The frontend does not generate spreadsheets.

## Single Cycle Export

Endpoint:

```text
GET /api/cycles/{id}/export.xlsx
```

Dashboard button:

```text
Download Cycle XLSX
```

## Batch Export

Endpoint:

```text
GET /api/batches/{id}/export.xlsx
```

Dashboard button:

```text
Download Batch XLSX
```

## Workbook Structure

The workbook follows the A:AL reference layout from the evaluated report sample:

- `A1:AL1` merged title: `Retort Report`
- row 2 grouped headings
- row 3 detailed source/statistic headings
- data rows start at row 4
- sheet name: `Average Time`

Column groups:

- `A:H` general cycle details
- `I:P` Water Filling Then Steam Input Start
- `Q:S` Step_1&2 Heating
- `T:AA` Step_3,4,5 Sterilization
- `AB:AJ` Step_6,7&8 Cooling
- `AK` Remarks
- `AL` Status

Statistics are calculated by the backend and written as values:

- Minimum
- Maximum
- Median
- Flow Rate Average

Duration cells use Excel formulas where practical:

```text
H = G - F
K = J - I
S = R - Q
V = U - T
AD = AC - AB
```

Timestamp references also follow the workbook mapping:

```text
Q = F
T = R
AB = U
AC = G
```

Cooling `AE` (`Min From R1B Report`) is intentionally separate from calculated cooling minimum `AF`.
For this MVP, when no explicit summary-level minimum field is parsed from R1B, `AE` is populated from the lowest Flow reading directly observed in R1B during Cooling Start To End Of Cycle.

## Formatting

The exporter applies:

- merged group headings
- bold headers
- centered headings
- wrapped header text
- freeze panes
- reasonable column widths
- numeric formatting for flow values
- date/time formatting

## Validation

Tests verify:

- output is a valid XLSX
- workbook opens with `openpyxl`
- expected headers exist
- exact A:AL column contract
- one cycle creates one data row
- reference formulas exist
- no obvious local path references are written
